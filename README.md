# ИИ на практике

Открытая база разборов и материалов канала **«ИИ на практике»**. Авторские пересказы курсов Stanford, метафоры для собственников бизнеса, готовые сценарии видео.

Автор — Виктор Зайцев. 46 лет, Казань. 20 лет в бизнесе, 5 компаний с нуля. С 2024 года изучаю искусственный интеллект изнутри и рассказываю о нём так, как сам теперь понимаю — для собственников, без жаргона и математики.

## Что внутри

### Лекции

Авторские интерпретации академических курсов по AI/ML. Не дословные переводы — мои разборы для русскоязычных собственников бизнеса.

- [01. Как работают трансформеры](./lectures/01-transformers-explained/) — пересказ Lecture 1 курса Stanford CME 295 с метафорами из реального бизнеса. Сценарий видео 25-30 минут.
- [02. Как обучают большие языковые модели](./lectures/02-llm-training/) — пересказ Lecture 4 курса Stanford CME 295 с метафорами из реального бизнеса. Сценарий видео ~28 минут.

### В работе

- 02. Как обучают большие языковые модели
- 03. RAG и базы знаний на простом языке
- 04. Агенты — что это и зачем они вашему бизнесу
